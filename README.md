# Deeply Ocean

Site em estilo parallax que conduz o usuário por uma descida visual pelas camadas do oceano, explorando a atmosfera, a profundidade e a sensação de imersão em cada zona marítima, contendo navegação por scroll, transições visuais, texto editorial e efeito de cores para transmitir a progressão da descida até as regiões mais profundas.
